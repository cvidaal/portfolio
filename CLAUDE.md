# Portfolio de Carlos Vidal

Reglas permanentes:

- No inventar experiencia, métricas ni responsabilidades.
- No presentar a Carlos como senior ni experto en tecnologías que aún aprende.
- Diferenciar siempre experiencia profesional de proyectos/productos propios.
- Prioridad de mensaje: Go, backend, APIs, integraciones, testing.
- Rendimiento y accesibilidad no se sacrifican por efectos.
- No mencionar Claude Code ni desarrollo asistido por IA en los textos del portfolio.
- Marcar con `[PLACEHOLDER]` todo texto pendiente de Carlos.

## Comandos

- `npm run dev`: servidor de desarrollo (Astro).
- `npm run build`: build estático en `dist/`.
- `npm run preview`: sirve el build.
- `npm test`: tests unitarios (Vitest).
- `npm run test:e2e`: tests e2e (Playwright contra `astro preview`; ejecutar antes `npm run build`).
- `npm run lhci`: Lighthouse CI.

## Textos

Los textos van en `src/content` / `src/i18n`, nunca dentro de los componentes.
