# Iteración 2 — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicar los cambios aprobados en la iteración 2: menú con la cara de Carlos y favicon nuevo, entrada al juego tipo arcade con los logros en un panel, carteles más contenidos, experiencia con tarjetas y textos nuevos (incluida Aeternum), Sobre mí visible y contacto con iconos.

**Architecture:** Mismo proyecto Astro 7 + islas React de la rama `rediseno-portfolio`. Todos los textos en `src/i18n/es.ts`. Se reutilizan el bus (`src/lib/bus.ts`), la isla del juego (`src/islands/game/*`) y el script de copiar email.

**Tech Stack:** Astro 7, React 18, CSS con variables, Vitest, Playwright (+ axe), sharp (scripts), `simple-icons` (iconos de marca, solo en build).

**Spec:** `docs/superpowers/specs/2026-11-06-iteracion-2-design.md` (y, para las restricciones globales, `docs/superpowers/specs/2026-11-04-rediseno-portfolio-design.md`). Boceto: `docs/superpowers/prototypes/ajustes-iteracion-2.html`.

## Global Constraints

- Restricciones globales de la iteración 1 vigentes (paleta, tipografías, texto legible sin JS, reduced motion, 320–390 px sin scroll horizontal, Lighthouse ≥ 90 rendimiento y accesibilidad, textos en `es.ts`, ningún `[PLACEHOLDER]` en producción, sin emojis en la interfaz, no inventar datos, no mencionar Claude Code ni IA como herramienta de desarrollo).
- Tokens existentes: `--accent`, `--accent-hi`, `--on-accent` (texto pequeño sobre acento), `--bg`, `--paper`.
- Textos de experiencia y Sobre mí: literales de la spec de la iteración 2, secciones 4 y 5.
- `npm run check`, `npm test` y `npm run build && npm run test:e2e` en verde al final de cada tarea.

## Review Focus

1. Sin JS: la barra de navegación debe verse (no puede quedarse oculta para siempre) y la tarjeta arcade no debe aparecer → Task 1 y Task 2.
2. El panel de logros: foco atrapado, Escape cierra y devuelve el foco al disparador, y no se puede abrir dos veces → Task 2.
3. Favicon a 16 px reconocible (no un borrón rojo) → Task 1 (revisión visual con captura ampliada).
4. Hueco de logo sin logo: iniciales, nunca una imagen rota ni un logo inventado → Task 3.
5. Rejilla de contacto a 320 px: sin desbordar y con objetivos ≥ 44 px → Task 4.
