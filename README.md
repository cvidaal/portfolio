## 🚀 Sobre el Proyecto

Este repositorio contiene el código fuente de mi portfolio personal. Diseñado desde cero con un enfoque en **Minimalismo**, **Performance** y **Experiencia de Usuario (UX)**.

El objetivo no fue solo mostrar mi CV, sino demostrar mi capacidad para construir interfaces modernas, limpias y responsive utilizando el ecosistema actual de React.

## 🛠 Stack Tecnológico

He utilizado un stack moderno para asegurar velocidad de carga y mantenibilidad:

- **Core:** [React](https://reactjs.org/) (Arquitectura basada en componentes funcionales).
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/) (Para un código robusto y libre de errores).
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first framework para un diseño rápido y responsive).
- **Bundler:** [Vite](https://vitejs.dev/) (Para un entorno de desarrollo instantáneo y build optimizado).
- **Iconos:** [Lucide React / Heroicons](https://lucide.dev/) (Iconografía SVG ligera).
- **Deploy:** Vercel/Netlify (CI/CD automático).

## ✨ Características Clave

- **📱 Fully Responsive:** Diseño adaptativo (Mobile-First) que funciona perfecto en móvil, tablet y desktop.
- **⚡ High Performance:** Optimización de assets y carga rápida (95+ en Google Lighthouse).
- **🎨 UI/UX Moderna:** Uso de espacios en blanco, tipografía limpia y paleta de colores coherente.
- **♿ Accesible:** Estructura semántica HTML5 y contrastes adecuados.
